# Netflix Clone

A static Netflix-inspired landing page built with HTML and internal CSS. The project recreates a streaming homepage with a full-screen hero, navigation controls, email signup prompts, trending show cards, responsive feature sections, and a footer link grid.

> This is a front-end practice project only. It is not affiliated with Netflix.

## Live Demo

[Open the Netflix Clone demo](https://ss-vidit.github.io/CSS/CSS/32-netflix-clone/)

## Features

- Netflix-style hero section with dark image overlay
- Header with logo, language button, and sign-in button
- Email signup forms in the hero and footer
- Horizontal trending section with numbered poster cards
- "More reasons to join" cards using gradient backgrounds
- Responsive layouts for tablet and mobile screens

## Tech Stack

- HTML5
- CSS3

## Run Locally

Open `index.html` directly in your browser.
