# CSS Grid Layout Practice

![CSS Grid Screenshot](assets/screenshots/css-grid.png)

A CSS practice page focused on grid columns, spacing, and item placement.

## What This Covers

- `display: grid`
- `repeat()` and `minmax()`
- Row and column gaps
- `place-content`
- `justify-items`, `align-items`, and item self-alignment
