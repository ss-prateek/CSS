# Spotify Download Page UI

A static HTML and CSS practice project that recreates a Spotify-style download landing page with a navigation bar, centered hero section, promotional text, and platform download cards.

> This is a front-end practice project only. It is not affiliated with Spotify, and the buttons link to Spotify's official download page.

## Preview

![Spotify Download Page Screenshot](assets/screenshots/spotify-download-page.png)

## Live Demo

[Open the Spotify Download Page demo](https://ss-vidit.github.io/CSS/CSS/28-spotify-download/)

## Features

- Spotify-inspired green and black visual theme
- Header navigation with logo and menu items
- Hero section with a primary download call to action
- Three platform cards for Android, iOS, and Windows
- Single-file HTML project using internal CSS

## Tech Stack

- HTML5
- CSS3

## Run Locally

Open `index.html` directly in your browser.
